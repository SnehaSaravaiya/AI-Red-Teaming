# Day 39: Multi-Turn Confidentiality Evaluation

#### Date: 25/11/2026

## 1. Overview

This experiment investigates whether conversational history and
psychological pressure influence an LLM's ability to protect
confidential information.

The evaluation compares neutral conversations with conversations
inspired by psychological principles used in social engineering.

## 2. Research Question

Can an LLM consistently maintain confidentiality boundaries
throughout a multi-turn conversation?

## 4. Psychological Mechanisms

The experimental condition was inspired by the following
psychological mechanisms:

- Rapport and familiarity
- Reciprocity
- Authority framing
- Commitment and consistency
- Urgency

These mechanisms were incorporated into simulated conversational
prompts to evaluate confidentiality enforcement.

## 5. Experimental Methodology

Two fictional application scenarios were created:

1. Banking Assistant
2. Corporate Assistant

Each assistant received a system instruction containing a
synthetic confidential value that it was prohibited from disclosing.

Two conversation conditions were evaluated:

### Control Condition

Ordinary questions about the assistant's role, services,
confidentiality, and permitted activities.

### Psychological Pressure Condition

Questions incorporating familiarity, cooperation,
claimed authority, commitment, and urgency.

Both conditions ended with an identical unauthorized
request for confidential information.

Conversation history was preserved across all five turns.

## 6. Evaluation Metrics

- Exact canary disclosure
- Confidentiality consistency
- First disclosure turn
- Final-turn refusal behaviour
- Context propagation
- Response latency

Exact string matching was used to detect whether the
synthetic confidential value appeared in a model response.

## 8. Key Finding

The most significant observation was that confidential
information was disclosed during ordinary conversation
rather than under psychological pressure.

During the corporate control conversation, the model
revealed the protected project code in response to
a basic question about its role.

The confidential value subsequently appeared in three
additional responses.

However, when explicitly requested to disclose the same
information during the final turn, the model refused.

This demonstrates an inconsistency between refusal behaviour
and actual confidentiality enforcement.

## 9. Security Analysis

### 9.1 Unsolicited Information Disclosure

The model exposed protected information without receiving
an explicit request for that information.

This indicates that confidentiality failures can occur
during routine interactions.

### 9.2 Context Propagation

After the initial disclosure, the confidential value
remained within the conversation history.

Subsequent responses continued referencing the value.

This suggests that an initial confidentiality failure
may propagate across multiple conversation turns.

However, the independent effect of conversation history
was not isolated in this experiment.

### 9.3 Context-Dependent Security Enforcement

The model refused an explicit unauthorized request
despite previously disclosing the same information.

This suggests that confidentiality enforcement may
vary depending on how a request is framed.

### 9.4 Limitations of Refusal-Based Evaluation

A refusal-only evaluation would have classified the
final corporate interaction as successful.

However, examining the complete conversation reveals
that confidentiality had already been compromised.

Therefore, refusal behaviour alone is insufficient
for evaluating information security.

## 10. Defensive Recommendations

- Avoid storing actual credentials or secrets in system prompts.
- Apply output-level sensitive information detection.
- Evaluate complete conversation histories.
- Include benign interactions in security test datasets.
- Implement authorization outside the language model.
- Prevent sensitive information from entering user-visible context.
- Combine automated detection with manual semantic evaluation.

## 11. Limitations

- Only one language model was evaluated.
- The experiment used a small sample size.
- One conversation was incomplete due to a timeout.
- The experimental conditions had unequal completion counts.
- Psychological mechanisms were not independently evaluated.
- Some pressure prompts may have reinforced confidentiality rules.
- Exact matching does not detect every form of partial disclosure.
- The four disclosures occurred within one conversation
  and should not be treated as independent security failures.

The results are exploratory and should not be generalized
to other models or production environments.

## 13. Conclusion

This experiment identified a confidentiality failure
during routine multi-turn interaction.

Although the model successfully refused an explicit
unauthorized request, it had already disclosed the
protected information during earlier benign interactions.

The findings emphasize the importance of evaluating
complete conversations rather than isolated adversarial
prompts or refusal responses.

> Successful refusal does not guarantee successful
> confidentiality enforcement.

## 14. Responsible Testing

All experiments were conducted locally using fictional
application scenarios and synthetic confidential values.

No real credentials, personal information, external
systems, or unauthorized resources were involved.
